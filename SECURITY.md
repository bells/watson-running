# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/bells/watson-running/security/advisories/new).
Do not include credentials, private route data, or exploit details in a public issue.

Include the affected version or commit, steps to reproduce, expected impact, and
any suggested mitigation. Maintainers will review the report and coordinate a fix
before public disclosure.

## Supported version

Security fixes target the current `main` branch. Earlier commits and tags are not
maintained as separate release lines.
