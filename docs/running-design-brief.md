# Watson Running 界面设计 brief

本文件记录 `refresh-running-experience-and-toolchain` 实施前确认的方向。最终 token 数值、组件规则和截图应在真实页面完成后写入 `DESIGN.md`，以成品为准。

## 阅读方式与方向

这是个人跑步档案，公开访客与 Watson 本人的需求同等重要。访客先理解十年积累，再看年份与代表性训练；本人可以快速切换周期、找到记录并核对单次运动。视觉主张是“赛道记录册”：以记录、分段和真实路线形成运动节奏，而非套用健身营销页或后台卡片墙。

采用既有 Watson 标志和荧光黄识别，石墨深色与暖白浅色为两套完整主题。荧光黄用于可操作的重点和跑步数据，心率/海拔等曲线允许少量有图例的辅助色。数字使用等宽排版，单位紧贴数值且保持较低权重。动效限于筛选、定位和状态变化；减少动态效果时内容保持完整。设计参数：变化度 6、动效 3、信息密度 6。

## 语义 token 草案

| 用途 | 深色方向 | 浅色方向 | 约束 |
| --- | --- | --- | --- |
| 页面底色 | 石墨黑 `#14191d` | 暖白 `#f7f8fa` | 整页同一主题 |
| 主文字 | 冷白 `#e6edf2` | 炭黑 `#202a33` | 正文需达到 WCAG AA |
| 跑步强调 | 既有荧光黄 `#e0ed5e` | 深橄榄 `#405000` | 浅色背景上的荧光黄填充配深文字 |
| 次要文字 | 灰蓝 `#a6b2ba` | 灰蓝 `#687783` | 不用透明度弱化重要单位 |
| 焦点 | 高对比荧光黄 | 深橄榄 | 可见且不只靠颜色 |
| 曲线 | 心率/步频/海拔各有固定语义色 | 同语义色的亮色可读版本 | 配图例和文字值 |

IBM Plex Sans 与 IBM Plex Mono 是现有资产方向；远端字体加载失败时有系统字体回退。具体字体托管、颜色对比和断点须经实现后的实测确定。

## 状态样例与验收

- 地图瓦片失败：说明“地图暂时无法加载”，保留活动记录与详情入口，提供重试；不留下黑色空区域假装成功。
- 无路线或短路线：按公开数据如实说明状态，不从私有轨迹补画。
- 无心率/采样：显示“本次运动没有心率采样”，不画零值线。
- 空年份或空筛选：保留筛选控件，说明没有符合条件的记录，提供清除/切换范围。
- 详情文件失败：显示可恢复错误与返回路径，保留可用概览信息。
- 窄屏：记录呈纵向可点开的条目，地图置后；不要求用户横向滚动才能进入详情。
- 键盘/触摸：年份、筛选、记录、详情、主题和聊天均可独立操作；焦点明确，控件有足够触控尺寸。

页面完成后用桌面与窄屏截图成组评估首屏信息、对比度、断行、焦点和明暗主题；不得以本文的预期替代实际浏览器结果。
